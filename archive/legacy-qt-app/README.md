# Legacy Qt/C++ ZoomArchy implementation (archived)

This directory contains a **historical Qt Quick/qmake implementation** of ZoomArchy, preserved for reference.

## Status and scope

- **Not the current plugin:** this is not the current Omarchy/Quickshell plugin implementation.
- **Different architecture/runtime:** this codebase reflects an earlier standalone Qt/C++ (Qt Quick) application build/package flow and differs from the current plugin (`manifest.json` + `Overlay.qml`).
- **Historical/reference only:** files are retained for historical and reference purposes.
- **Not part of current plugin distribution:** nothing in this directory is required by, installed with, or distributed as part of the current Omarchy plugin.
- **Version/package metadata:** original metadata in these files may refer to earlier project states and should be treated as historical evidence.

## Support and validation

This archived implementation is **not currently supported or build-tested**. No build, runtime, packaging, or compatibility guarantees are provided.

## Contents

The archived group includes the historical source/build/packaging files preserved together (e.g. `zoomarchy.pro`, `main.cpp`, `zoomarchy.h`, `zoomarchy.cpp`, `ZoomArchyConfig.h`, `main.qml`, `assets.qrc`, `qml.qrc`, `app.desktop`, `install.inx`). Generated build artifacts, local environment files, binaries, and unrelated local directories are intentionally not included.
